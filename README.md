# 🗺️ Zelda GeoGuessr

> Браузерная игра в стиле GeoGuessr по миру _The Legend of Zelda: Breath of the Wild_.
> Угадайте место на карте Хайрула по скриншоту из игры!

## 🎮 Как играть

1. **Выберите серию** — каждая содержит 5 раундов разной сложности.
1. **Рассмотрите скриншот** — можно увеличить, перемещать и свернуть.
1. **Поставьте маркер** на карте, кликнув в предполагаемое место.
1. **Нажмите «Подтвердить»** — увидите расстояние до правильной точки и очки.
1. **После 5 раундов** — итоговый результат.

### Система очков

| Точность        | Очки   |
| --------------- | ------ |
| Идеально (0 px) | 5 000  |
| ~500 px         | ~3 900 |
| ~1 000 px       | ~3 000 |
| ~2 000 px       | ~1 840 |
| ~4 000 px       | ~675   |
| Далеко          | → 0    |

Максимум за серию — **`раундов × 5 000` очков** (динамически).

Формула: `S = 5000 × e^(−d / 2000)`, где `d` — расстояние в пикселях карты.

## 🚀 Запуск

### Статический (без сервера)

Откройте `index.html` через `file://` в браузере. Карта отображается как одно изображение (`map/map_high.jpg`), редактор скачивает `locations_data.js`.

### С Go-сервером (рекомендуется для редактирования)

```bash
cd server
go run .
# или
build.bat   # → ZeldaGeoGuessr.exe
```

Сервер найдёт свободный порт (8080+), откроет браузер. Включены: тайловая карта, CRUD-редактор, загрузка файлов, бэкапы.

## 🛠️ Технологии

| Технология                              | Назначение                              |
| --------------------------------------- | --------------------------------------- |
| HTML / CSS / JavaScript                 | Вся игра — без фреймворков              |
| [Leaflet 1.9.4](https://leafletjs.com/) | Интерактивная карта с зумом и маркерами |

Leaflet подключается через CDN. Go-сервер — опционально, для редактора и тайлов.

## ➕ Добавление своих локаций

### 1. Подготовьте скриншоты

Сделайте скриншоты в игре. Сохраните в папку `locs/` с именами вида:

```text
location_s{номер_серии}_i{номер_раунда}.png
```

### 2. Определите координаты

Откройте карту `map/map_high.jpg` в графическом редакторе и запишите координаты (x, y) каждой локации в пикселях. Начало координат — левый верхний угол, X вправо, Y вниз.

Либо используйте **вкладку «📝 Редактор»** в инструментах: кликайте на карту, чтобы задать координаты, и загружайте изображения прямо из браузера.

### 3. Добавьте серию в `locations_data.js` (или через редактор)

```javascript
{
    "id": 4,
    "name": "Моя серия: Название",
    "rounds": [
        { "image": "location_s04_i01.png", "x": 1234, "y": 5678 },
        { "image": "location_s04_i02.png", "x": 9876, "y": 5432 },
        { "image": "location_s04_i03.png", "x": 4500, "y": 7800 },
        { "image": "location_s04_i04.png", "x": 11000, "y": 3200 },
        { "image": "location_s04_i05.png", "x": 6000, "y": 12000 }
    ]
}
```

### 4. Готово

Перезагрузите страницу — новая серия появится в меню.

## 🗺️ О карте

Игра использует карту Хайрула размером **18 000 × 15 000** пикселей в пиксельной системе координат.

### Режимы отображения

- **Тайловый** (через HTTP): нарезанные тайлы в `map_tiles/`, автоматический фолбэк на imageOverlay при 404.
- **Одиночное изображение** (через `file://`): `map/map_high.jpg` через `L.imageOverlay` с `CRS.Simple`.

Рекомендуемое разрешение файла `map/map_high.jpg`:

| Разрешение        | Размер файла | Качество при приближении    |
| ----------------- | ------------ | --------------------------- |
| 4 500 × 3 750     | ~3 МБ        | Среднее                     |
| **9 000 × 7 500** | **~10 МБ**   | **Хорошее (рекомендуется)** |
| 12 000 × 10 000   | ~18 МБ       | Отличное                    |
| 18 000 × 15 000   | ~25 МБ       | Максимальное                |
