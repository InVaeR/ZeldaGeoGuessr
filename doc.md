# Техническая документация Zelda GeoGuessr

## 📖 Общее описание

Zelda GeoGuessr – это веб-игра на чистом JavaScript. Поддерживает тайловую карту (через HTTP) и одиночное изображение (через `file://`). Основная цель – угадать местоположение по скриншоту.

## 🧩 Структура проекта

```

│   └── game.js          # Основная игровая логика
├── server/

```

## 🗺️ Карта и координаты

- **Размер**: 18 000 × 15 000 пикселей.
- **Система координат**: начало (0,0) – левый верхний угол, X растёт вправо, Y – вниз.
- **Привязка к Leaflet**: используется `L.CRS.Simple`; точка (x, y) преобразуется в `L.latLng(-y, x)`.  
  Это сделано для того, чтобы ось Y на карте шла сверху вниз, как в пиксельной системе.
- **Режимы отображения:**
  - Тайловый (`USE_TILES=true`): нарезанные тайлы в `map_tiles/` — при HTTP-доступе.
  - Одиночное изображение (`USE_TILES=false`): `map/map_high.jpg` через `L.imageOverlay` — при `file://`.
  - Автофолбэк: при 3+ ошибках загрузки тайлов карта переключается на imageOverlay (с проверкой доступности).

### Ключевые функции в `map.js`

- `pxToLatLng(x, y)` – преобразование в Leaflet-координаты.
- `latLngToPx(latlng)` – обратное преобразование.
- `create(containerId)` – создание карты (тайлы или imageOverlay).
- `createGuessMarker(latlng)` – красный маркер ответа игрока.
- `createCorrectMarker(latlng)` – зелёный маркер правильного ответа.
- `createResultLine(from, to)` – жёлтая линия между ними.

## 📊 Данные локаций (`locations_data.js`)

Файл содержит массив `series`. Каждая серия:

```js
{
  "id": 1,
  "name": "Название серии",
  "rounds": [
    { "image": "имя_файла.png", "x": 4500, "y": 3800 },
    ...
  ]
}
```

- `image` – имя файла в папке `locs/`.
- `x`, `y` – координаты правильного ответа в пикселях карты.

## 🧮 Подсчёт очков

Функция `Scoring.score(distance)` использует формулу:

```js
score = Math.round( MAX_ROUND_SCORE * Math.exp(-distance / CALIBRATION_D) )
```

- `MAX_ROUND_SCORE = 5000`
- `CALIBRATION_D = 2000` (подбирается эмпирически)

Расстояние вычисляется по Евклидовой метрике:  
`sqrt((x1-x2)^2 + (y1-y2)^2)`.

## 🖥️ Go-сервер

Go-сервер (`server/main.go`) раздаёт статику и предоставляет API:

| Маршрут | Метод | Описание |
|---------|-------|----------|
| `/api/health` | GET | Проверка, что сервер жив |
| `/api/series` | GET | Чтение серий из `locations_data.js` |
| `/api/series/save` | POST | Сохранение серий + бэкап |
| `/api/upload-location` | POST | Загрузка изображения в `locs/` |
| `/api/delete-location-image` | POST | Удаление изображения из `locs/` |

Сервер автоматически находит свободный порт (начиная с 8080), создаёт бэкапы при сохранении, чистит старые бэкапы (хранит до 20).

### Защита

- `Cache-Control: no-cache` для `/locs/*` и `locations_data.js`.
- Проверка Origin/Referer на API-эндпоинтах (только localhost).
- `filepath.Rel` для проверки path traversal при загрузке/удалении.

## 🖼️ Просмотрщик изображений

Реализован в `ui.js` в объекте `UI`. Позволяет:

- Увеличивать/уменьшать изображение колёсиком мыши или кнопками.
- Перетаскивать (drag) для панорамирования.
- Сбрасывать масштаб и центрирование двойным кликом или кнопкой «⟲».
- Закрывать по `Escape` или кнопке «✕».

## 🧑‍💻 Разработка

Все модули собраны в глобальные объекты (`UI`, `GameMap`, `Scoring`, `CONFIG`, `Tools`, `Game`, `Api`), чтобы упростить доступ.

### Добавление серий

1. Через **Редактор** (вкладка «📝 Редактор» в инструментах): создавайте серии, раунды, загружайте изображения.
2. Напрямую в `locations_data.js` (формат описан выше).

### Сервер

```bash
cd server
go run .              # разработка
.\build.bat           # сборка в ZeldaGeoGuessr.exe
```

При `file://`-доступе редактор скачивает `locations_data.js` вместо сохранения на сервер.

### Редактор

- Live-sync формы: изменения применяются мгновенно.
- «Отмена» честно восстанавливает снапшот раунда.
- Валидация перед сохранением: координаты в пределах CONFIG.MAP_WIDTH×CONFIG.MAP_HEIGHT, непустые имена файлов, проверка дубликатов.
- Удаление файлов с диска откладывается до сохранения (pendingDeletes) с проверкой перекрёстных ссылок.
- Cache-busting (`?v=Date.now()`) при загрузке превью и игровых изображений.
